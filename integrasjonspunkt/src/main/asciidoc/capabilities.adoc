=== Example 7 - ServiceRegistry temporarily unavailable

If ServiceRegistry, or a service it depends on, is temporarily unavailable, the service responds with `503 Service Unavailable`.
This is a temporary condition, and the request can be retried later.
If the receiver is not found in ServiceRegistry, the service responds with `404 Not Found`.
